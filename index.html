Getting it onto your phone

It's a direct APK, so installing takes one extra step.

RaceBox GPS isn't on Google Play, so Android will ask permission the first time you install something from outside the store. That's expected — here's the full path.

01

Download & allow the source

Tap Download APK. When Android blocks the install, tap Settings on the prompt and allow installs from this browser.

02

Install

Open the downloaded file and tap Install on the confirmation screen. Play Protect may scan it first — that's normal.

03

Open & grant Bluetooth

Launch the app and allow the Bluetooth permission it asks for. That's what lets it talk to your RaceBox.

Only install APKs from sources you trust. This one is built from the source in this same project — if you're distributing it further, let people know where it came from so they're not installing it blind.
